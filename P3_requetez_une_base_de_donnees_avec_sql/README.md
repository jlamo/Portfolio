
#  Projet 3 — Requêtez une base de données avec SQL

##  Contexte
Une entreprise dispose d'une base de données relationnelle et souhaite pouvoir en extraire des informations précises pour répondre à des besoins métiers variés (ventes, clients, produits, etc.).

##  Objectifs
- Comprendre le fonctionnement d'une base de données relationnelle.
- Écrire des requêtes SQL simples et complexes pour extraire, filtrer et agréger des données.
- Répondre à des demandes métiers précises à partir de requêtes SQL.

##  Compétences développées
- Écriture de requêtes SQL (SELECT, WHERE, JOIN, GROUP BY, sous-requêtes, etc.)
- Compréhension d'un schéma relationnel
- Interprétation des résultats de requêtes pour répondre à des besoins business

##  Technologies
- SQL
- SQLite

##  Contenu du dossier
- Scripts SQL des requêtes réalisées
- Schéma de la base de données
- Réponses aux questions métiers posées dans l'énoncé du projet

##  Résultat
Un ensemble de requêtes SQL permettant de répondre aux différentes demandes d'analyse formulées par l'entreprise.
