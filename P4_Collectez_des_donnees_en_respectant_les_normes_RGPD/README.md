
#  Projet 4 — Collectez des données en respectant les normes RGPD

##  Contexte
Dans le cadre de la collecte et de l'exploitation de données personnelles, une entreprise doit s'assurer de respecter le Règlement Général sur la Protection des Données (RGPD). Ce projet consiste à mettre en place une démarche de collecte de données conforme à cette réglementation.

##  Objectifs
- Identifier les données à caractère personnel dans un jeu de données.
- Comprendre les grands principes du RGPD (finalité, minimisation, durée de conservation, consentement).
- Mettre en place une méthodologie de collecte de données respectueuse de la vie privée.

##  Compétences développées
- Compréhension du cadre juridique du RGPD appliqué à la donnée
- Anonymisation / pseudonymisation des données
- Documentation d'une démarche de conformité (registre de traitement)

##  Outils
- Power BI (Power Query)
- Documentation RGPD

##  Contenu du dossier
- Documentation / registre de traitement des données
- Script(s) de collecte et de traitement des données
- Synthèse de la démarche de conformité

##  Résultat
Une démarche de collecte de données documentée et conforme aux exigences du RGPD.
