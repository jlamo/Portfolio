
#  Projet 5 — Manipulez une base de données avec SQL pour suivre la satisfaction client

##  Contexte
Une entreprise souhaite suivre la satisfaction de ses clients à partir des données stockées dans sa base de données (commandes, avis, délais de livraison, etc.). L'objectif est de mettre en place des requêtes permettant de suivre cet indicateur clé.

##  Objectifs
- Manipuler une base de données relationnelle liée à la relation client.
- Construire des requêtes SQL permettant de mesurer et suivre la satisfaction client (délais, notes, réclamations).
- Restituer des résultats exploitables pour les équipes métiers.

##  Compétences développées
- Requêtes SQL avancées (jointures multiples, agrégations, sous-requêtes)
- Construction d'indicateurs de suivi (KPI) à partir de données brutes
- Interprétation de résultats orientés satisfaction client

##  Technologies
- SQL
- MySQL (ou équivalent)

##  Contenu du dossier
- Scripts SQL des requêtes réalisées
- Indicateurs de satisfaction client obtenus
- Synthèse des résultats

##  Résultat
Un ensemble d'indicateurs SQL permettant de suivre dans le temps la satisfaction des clients de l'entreprise.
