
#  Projet 6 — Optimisez la gestion et nettoyez les données du stock d'une boutique

##  Contexte
Une boutique dispose de données de stock incomplètes, dupliquées ou mal structurées, rendant difficile le suivi de son inventaire. L'objectif est de nettoyer ces données et de proposer des pistes d'optimisation de la gestion du stock.

##  Objectifs
- Identifier et corriger les anomalies dans un jeu de données de stock (doublons, valeurs manquantes, incohérences).
- Structurer les données pour faciliter leur exploitation.
- Proposer des recommandations pour optimiser la gestion des stocks.

##  Compétences développées
- Nettoyage et préparation des données (data cleaning)
- Détection d'anomalies et de valeurs aberrantes
- Analyse de données pour la prise de décision opérationnelle

##  Technologies
- Python (Pandas, NumPy) et/ou Excel

##  Contenu du dossier
- Notebook / fichier de nettoyage des données
- Données avant / après nettoyage
- Recommandations d'optimisation du stock

##  Résultat
Un jeu de données de stock fiabilisé, accompagné de recommandations concrètes pour améliorer sa gestion.
