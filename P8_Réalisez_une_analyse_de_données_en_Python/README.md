
#  Projet 8 — Réalisez une analyse de données en Python

##  Contexte
Une entreprise souhaite exploiter un jeu de données brut afin d'en tirer des enseignements exploitables pour la prise de décision. L'objectif est de mener une analyse de données complète en Python, du nettoyage jusqu'à la restitution des résultats.

##  Objectifs
- Nettoyer et préparer un jeu de données pour l'analyse.
- Réaliser une analyse exploratoire (statistiques descriptives, distributions, corrélations).
- Visualiser et interpréter les résultats afin d'en tirer des conclusions actionnables.

##  Compétences développées
- Nettoyage et préparation des données
- Statistiques descriptives et tests statistiques
- Data visualisation avec Python

##  Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn

##  Contenu du dossier
- Notebook(s) d'analyse
- Visualisations produites
- Synthèse des résultats et conclusions

##  Résultat
Une analyse de données complète mettant en évidence des tendances et enseignements exploitables par l'entreprise.
